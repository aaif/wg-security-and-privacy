## Topics Discussed

- **Chairs update** — Alex was unable to join from Tokyo, so Junjie ran the meeting. Alex is working to set up an alternate meeting on the off weeks of this biweekly cadence at a time that works better for APAC participants. Fernando noted the 10 am Pacific slot already lands around 9-10 pm for China-based members, and Matthew suggested an early enough slot could draw in AAIF CTO Manik from Australia.
- **Taxonomy browser tool** — Matthew shared a new taxonomy browser that lets contributors draft definitions with their own AI provider and tokens, then automatically opens a PR whose commit message records which LLM was used and how much of the generated definition was edited by a human. The tool was prompted by a burst of AI-assisted agentic definitions from an outside contributor and gives the group better observability into how definitions are produced.
- **Taxonomy / Landscape** — Two weeks ago the workstream closed 10-15 definitions across five PRs, and last week it reviewed its own process and moved toward merging PRs after a set period when there are no objections, since fixes can follow in Git. An individual outside the meeting opened many PRs, and Matthew reached out to coordinate on a strategy for handling them. Jautau was welcomed back and asked to keep reviewing terms and other working groups' PRs.
- **Managing unsolicited PRs and comments** — Bar described how another open source project she works on blocked PRs from non-core contributors, requiring an issue first and an assignment before a PR is accepted, and suggested the same for this WG. Fernando clarified the recent influx was comments on Erin's PR rather than a PR itself, and Junjie will raise the question of how to handle one-off or agent-generated contributions from the public in the chairs meeting now that AAIF has opened the working groups to everyone.
- **GitHub project board permissions** — Govindaraj cannot assign cross-WG issues to specific people on the review checklist project board even though Krishna confirmed he has permissions, while members of Observability and Tracing can assign on their board. The group wants issue assignment limited to sub-workstream leads so ownership of each deliverable is clear, and Junjie will follow up with Christina and Dana on granular permission controls.
- **Threat modeling** — Fernando submitted the first draft PR and has not returned to it while focused on the best practices guide. He plans to merge best practices first, then move to threat modeling and alternate between the two. He is also looking for a morning slot so APJ members can join the workstream meeting, and co-lead Alon has not responded on Discord since June, so Fernando will try email.
- **Orientation for new members** — Moushumi joined for the first time and asked where workstreams are tracked. Junjie pointed to the `workstreams` path in GitHub with a README under each workstream, and Matthew noted the Google Drive linked in the meeting invite holds brainstorming material that moves to GitHub once it is ready for formal review.
- **Design patterns catalog** — Sagar and Ben were absent. Junjie surfaced an open design pattern PR for an isolated runtime draft from a taxonomy participant who is not a listed design patterns contributor, and Erin was only aware of it because it referenced her PR. The group will confirm whether it belongs to the workstream.
- **Best practices guide** — The first version is in review with roughly 88 comments and new ones still arriving. Fernando will address Bar's recent comments, apply simple fixes directly, convert the more involved ones into GitHub issues referenced from the PR, and then merge with a note that further changes should come through issues and PRs. Samantha confirmed code suggestions on comments already work in the repo, and Matthew asked reviewers to use them to lighten the load on Fernando. Fernando reminded the group the document belongs to the WG and invited everyone to edit it.
- **PR review timelines** — David proposed writing a comment deadline into the contributing doc so review windows become a standing agreement rather than a per-PR negotiation. Fernando agreed to add it to `CONTRIBUTING.md`, and the group confirmed merges to main only happen through PRs, so branch protection is in place.
- **Cross-WG review checklist** — Govindaraj reported that a few members are working the issues raised on cross-WG collaboration, and the main blocker is representation. Security and Privacy members already cover Observability and Tracing and Identity and Trust well, while Accuracy and Reliability, Workflow and Integration, Governance, and Agentic Commerce have little to no participation despite him tagging their chairs on Discord. He flagged that Agentic Commerce is pursuing delegated payment orchestration that overlaps identity and trust, and asked how A2A and Agent Router becoming Linux Foundation projects will be handled from an overlap standpoint.
- **Meeting notes and automation** — Govindaraj noted that other groups' Git documentation is incomplete because much of the work stays in Google Docs, which makes it hard to trace what changed over time. He and Matt are looking for API access to pull LFX recordings and AI summaries so summaries could be generated and committed automatically across working groups, following the prompt-based process Alex uses for this group's notes.
- **News** — OpenAI, Google, and Anthropic announced a stronger focus on testing and safety over the weekend, which the group received with some skepticism given the pace of model releases. David recounted a newly released model that, with computer control tools off, enabled remote control in his OS and moved his mouse to click a Create PR button during a GitHub outage. Junjie shared a proposed Congressional act that would require agents and bots to declare their identity and intent, and noted related policy discussions from DEF CON's Policy Village.
- **ETSI TC SAI** — Hsiao-Ying reported that ETSI TC SAI chartered a new work item on cybersecurity requirements for AI services and systems, extending an existing European Norm to cover AI agents, with work progressing over the next year. She introduced this WG's work there and asked whether a formal bidirectional information exchange can be established between the two bodies.
- **Eclipse Enclave** — Matthew joined the Sovereign AI Interest Group and flagged Eclipse Enclave, a sandbox for AI agents built on microVMs rather than Docker, which makes constraints such as disabling network access much harder for an agent to bypass. He offered to bring the maintainers in to present if there is interest.
- **Dallas chapter event** — The AAIF Dallas chapter in-person event is on 2026-09-26 and a presenter dropped out at the last minute. Govindaraj is assembling a talk on AIF projects and taking open standards to production with agents.md, Goose, MCP, A2A, Agent Gateway, and Agent Router, and welcomed collaboration so the material can be reused at other AIF events.
- **Conferences** — Hsiao-Ying will be at the Amsterdam conference later this week, where a lunch gathering is being organized on Thursday via the Discord channel. Junjie will attend the San Jose conference next month.
- **Agent Resource Discovery** — Govindaraj asked whether ARD is an AIF project. Junjie said it is not yet, and Govindaraj will send a Discord message to clarify its status and alignment.

## Decisions

- Comments on the best practices PR are cut off for the first version. Simple fixes will be applied directly, more involved comments become GitHub issues referenced from the PR, and further changes after merge will flow through issues and PRs.
- The WG will document a standing PR review window and comment deadline in `CONTRIBUTING.md` so review timelines are an agreed norm.
- Taxonomy PRs will be merged after a set period when no objections are raised, with follow-up fixes handled in Git.
